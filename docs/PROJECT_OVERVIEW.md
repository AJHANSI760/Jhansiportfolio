# Portfolio Project Overview

## Purpose

This repository contains a Flutter web portfolio for presenting my
Computer Science and Engineering background, technical interests,
projects, skills, and professional links.

## Portfolio Goals

- Present my profile clearly to recruiters.
- Showcase software development and AI/ML interests.
- Make project information easy to explore.
- Provide access to my GitHub and LinkedIn profiles.
- Support desktop and mobile web layouts.

## Technology

- Flutter
- Dart
- Git and GitHub
- GitHub Actions
- GitHub Pages

## Project Maintenance

Before publishing changes:

1. Install dependencies with `flutter pub get`.
2. Run `flutter analyze`.
3. Run automated tests with `flutter test`.
4. Build the web version and verify the result.
5. Review the changes before committing and pushing.
